## ¿Qué es BDD Fácil?

BDD Fácil es una plataforma educativa para aprender bases de datos relacionales y no relacionales.

### Temas incluidos

- SQL
- SQL Server
- MongoDB
- Redis
- Cassandra
- Neo4j
- Modelado de Datos
- Normalización
