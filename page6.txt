Modelos de almacenamiento de datos  
SQL Server administra bases de datos OLTP y OLAP  
 Bases de datos OLTP  (On-Line Transactional 
Processing: procesamiento transaccional en linea) Son 
bases de datos orientadas al procesamiento de 
transacciones que involucra acciones de inserción, 
eliminación y actualización de datos . SQL Server permite 
que un gran número de usuarios 
realice transacciones y modif ique 
simultáneamente datos en tiempo real 
en bases de datos OLTP. Algunos 
ejemplos de bases de datos OLTP serían sistemas de transacciones 
bancarias y de billetes de avión.  
 Bases de datos OLAP  (On-Line An alytical Processing : procesamiento 
analítico en línea) En general estas bases de 
datos involucran acciones de consulta  La 
tecnología OLAP organiza y resume grandes 
cantidades de datos, de manera que un 
analista pueda evaluar los datos rápidamente 
en tiempo real.
