Introducción

Cuando creamos una tabla en una base de datos, definimos sus columnas, tipos de datos y restricciones. Sin embargo, con el tiempo pueden aparecer nuevas necesidades: quizás necesitamos almacenar un dato que antes no contemplábamos, cambiar el tipo de una columna o eliminar un campo que dejó de utilizarse.

Para realizar este tipo de cambios en SQL utilizamos la sentencia ALTER TABLE. Su función es modificar la estructura de una tabla que ya existe, sin necesidad de crearla nuevamente desde cero.

ALTER TABLE pertenece al grupo de sentencias DDL (Data Definition Language), utilizado para definir y administrar la estructura de los objetos de una base de datos.

En esta guía vamos a trabajar con ejemplos orientados a SQL Server. Veremos cómo agregar columnas, eliminar campos, cambiar sus definiciones y agregar restricciones a una tabla existente.

¿Qué aprenderás?

Al terminar este artículo vas a poder:

  • Comprender para qué sirve ALTER TABLE.
  • Reconocer la estructura general de esta sentencia.
  • Agregar nuevas columnas mediante ADD.
  • Eliminar columnas mediante DROP COLUMN.
  • Modificar la definición de una columna mediante ALTER COLUMN.
  • Agregar restricciones a una tabla existente.
  • Identificar qué aspectos revisar antes de modificar una estructura.

Sintaxis de ALTER TABLE

La sentencia ALTER TABLE comienza indicando el nombre de la tabla que queremos modificar. Después se especifica la operación que se desea realizar.

Su estructura general es:

ALTER TABLE nombre_tabla
    operacion;

La operación puede consistir en agregar una columna, eliminarla, modificar su definición o incorporar una restricción.

Estas son algunas de las estructuras que vamos a utilizar:

Agregar una columna

ALTER TABLE nombre_tabla
ADD nombre_columna tipo_dato;

Eliminar una columna

ALTER TABLE nombre_tabla
DROP COLUMN nombre_columna;

Modificar una columna

ALTER TABLE nombre_tabla
ALTER COLUMN nombre_columna nuevo_tipo_dato;

Agregar una restricción de clave primaria

ALTER TABLE nombre_tabla
ADD CONSTRAINT nombre_restriccion
PRIMARY KEY (nombre_columna);

La estructura exacta de cada operación depende del cambio que necesitemos realizar. Por eso, antes de escribir la sentencia, es importante identificar qué parte de la tabla queremos modificar.

Explicación de las operaciones de ALTER TABLE

1. ADD: agregar una columna

La operación ADD permite incorporar una nueva columna a una tabla existente. Para hacerlo, indicamos su nombre y el tipo de dato que almacenará.

Por ejemplo, imaginemos que tenemos una tabla de personas y necesitamos incorporar una columna para guardar un teléfono:

ALTER TABLE personas
ADD telefono VARCHAR(20);

Con esta instrucción agregamos la columna telefono a la estructura de la tabla personas.

No estamos creando una tabla nueva: estamos modificando una que ya existe.

2. DROP COLUMN: eliminar una columna

Si una columna deja de ser necesaria, podemos eliminarla mediante DROP COLUMN. Para ello debemos indicar el nombre del campo que queremos quitar. 

ALTER TABLE personas
DROP COLUMN telefono;

Esta instrucción elimina la columna telefono de la tabla personas.

Es importante distinguir esta operación de eliminar una tabla completa. DROP COLUMN afecta solamente a la columna indicada, mientras que DROP TABLE elimina la tabla.

3. ALTER COLUMN: modificar la definición de una columna

ALTER COLUMN permite cambiar la definición de una columna existente. Por ejemplo, podemos modificar el tipo de dato o ajustar la longitud permitida para un campo.

Supongamos que la columna apellido fue creada con una longitud de 50 caracteres y necesitamos ampliarla a 60: 

ALTER TABLE personas
ALTER COLUMN apellido VARCHAR(60) NOT NULL;

En este caso, modificamos la definición de la columna apellido, estableciendo un tipo VARCHAR con una longitud máxima de 60 caracteres y manteniendo la condición NOT NULL.

Antes de realizar este tipo de cambios, conviene revisar los datos existentes y las condiciones definidas para la columna.

4. ADD CONSTRAINT: agregar una restricción

ALTER TABLE también permite incorporar restricciones a una tabla que ya existe. Para ello se utiliza ADD CONSTRAINT, seguido del nombre y la definición de la restricción.

Por ejemplo, podemos agregar una clave primaria a una tabla:

ALTER TABLE proveedores
ADD CONSTRAINT pk_proveedor
PRIMARY KEY (id_proveedor);

La restricción se llama pk_proveedor y establece id_proveedor como clave primaria.

Para que esta operación pueda realizarse correctamente, la columna debe cumplir las condiciones necesarias para ser una clave primaria.

Ejemplo práctico: modificar la tabla personas

Vamos a retomar la tabla personas que utilizamos en el artículo de CREATE TABLE. En aquella oportunidad definimos campos como legajo, apellido, nombre, fecha de nacimiento, peso y altura.

Imaginemos que necesitamos realizar algunos cambios en su estructura. En lugar de crear otra tabla, podemos utilizar ALTER TABLE para actualizar la que ya existe.

Paso 1. Agregar una columna

Primero vamos a incorporar un campo para almacenar el teléfono de cada persona. 

ALTER TABLE personas
ADD telefono VARCHAR(20);

Ahora la estructura de personas cuenta con una columna adicional llamada telefono.

Paso 2. Modificar una columna

Supongamos que necesitamos ampliar la longitud permitida para el apellido. Podemos modificar su definición de la siguiente manera: 

ALTER TABLE personas
ALTER COLUMN apellido VARCHAR(60) NOT NULL;

La columna continúa siendo de tipo VARCHAR, pero ahora permite almacenar hasta 60 caracteres. También se mantiene la condición NOT NULL.

Paso 3. Eliminar una columna

Finalmente, imaginemos que el campo teléfono ya no será necesario. Podemos quitarlo de la tabla: 

ALTER TABLE personas
DROP COLUMN telefono;

Con esta última instrucción eliminamos la columna telefono.

Los tres ejemplos muestran cómo una misma tabla puede modificarse de distintas maneras a medida que cambian las necesidades de almacenamiento.

Caso práctico: adaptar una tabla a una nueva necesidad

Pensemos en una situación habitual durante el desarrollo de un sistema: inicialmente se crea una tabla para almacenar información básica de personas, pero después se decide incorporar un nuevo dato.

La tabla ya existe y contiene una estructura definida. En ese momento, volver a crearla no es necesariamente la solución. ALTER TABLE permite realizar el cambio directamente sobre la estructura existente.

Podemos representar esta situación con la siguiente secuencia:

  1. La tabla personas ya fue creada.
  2. Surge la necesidad de almacenar un teléfono.
  3. Utilizamos ADD para incorporar la nueva columna.
  4. Más adelante, el campo deja de ser necesario.
  5. Utilizamos DROP COLUMN para eliminarlo.

Las instrucciones SQL correspondientes son: 

-- Incorporar una columna
ALTER TABLE personas
ADD telefono VARCHAR(20);

-- Eliminar la columna incorporada
ALTER TABLE personas
DROP COLUMN telefono;

Este ejemplo permite observar que ALTER TABLE trabaja sobre una tabla existente y que cada operación modifica su definición.

Buenas prácticas al utilizar ALTER TABLE

Modificar una tabla puede afectar la estructura que utiliza una aplicación o un sistema. Por eso, antes de ejecutar una sentencia conviene revisar qué cambio se va a realizar y sobre qué columna.

  • Identificar la tabla correcta: verificar el nombre de la tabla antes de ejecutar la instrucción.
  • Revisar la columna: comprobar que el campo que queremos modificar o eliminar exista.
  • Elegir el tipo de dato adecuado: al utilizar ALTER COLUMN, revisar que la nueva definición sea compatible con los datos almacenados.
  • Evaluar las restricciones: comprobar si la columna participa en una clave primaria, clave foránea u otra restricción.
  • Utilizar nombres descriptivos: asignar nombres claros a las restricciones agregadas mediante CONSTRAINT.
  • Revisar los cambios antes de ejecutarlos: especialmente cuando se trata de eliminar columnas o modificar definiciones.

Errores comunes al utilizar ALTER TABLE

Al modificar una tabla pueden aparecer errores relacionados con los nombres, los tipos de datos o las restricciones existentes. Estos son algunos aspectos que conviene revisar.

1. Intentar modificar una columna inexistente

Si escribimos un nombre de columna que no pertenece a la tabla, SQL Server no podrá realizar la operación solicitada.

Antes de utilizar ADD, DROP COLUMN o ALTER COLUMN, verificá qué columnas forman parte de la tabla.

2. Confundir ADD con ALTER COLUMN

Ambas operaciones modifican la estructura, pero no hacen lo mismo. ADD incorpora una columna nueva, mientras que ALTER COLUMN cambia la definición de una columna que ya existe.

3. Eliminar una columna equivocada

DROP COLUMN elimina el campo indicado. Antes de ejecutarlo, es importante verificar que se trate de la columna correcta y que su eliminación no afecte información necesaria para el sistema.

4. Modificar una columna sin revisar sus datos

Un cambio de tipo de dato o de definición puede no ser compatible con los valores almacenados. Por eso, antes de utilizar ALTER COLUMN conviene revisar el contenido actual de la columna.

5. Agregar una clave primaria sin revisar la columna

Una clave primaria debe identificar de manera única cada registro. Si la columna contiene valores repetidos o valores NULL, no cumple las condiciones necesarias para establecerla como clave primaria.

Resumen: lo que tenés que recordar

ALTER TABLE es una sentencia DDL que permite modificar la estructura de una tabla existente. Se utiliza cuando necesitamos adaptar sus columnas o restricciones sin crear una tabla nueva.

Estas son las operaciones principales que trabajamos:

  • ADD: permite agregar una columna.
  • DROP COLUMN: elimina una columna existente.
  • ALTER COLUMN: modifica la definición de una columna.
  • ADD CONSTRAINT: permite incorporar una restricción a la tabla.

La elección de la operación depende del cambio que necesitemos realizar. Antes de ejecutar una sentencia, es importante identificar la tabla, revisar la columna y comprobar las restricciones que puedan estar relacionadas.

Practicar estas operaciones te permitirá comprender cómo evoluciona la estructura de una base de datos durante el desarrollo de un sistema.

¿Qué sigue después de ALTER TABLE?

Ya vimos cómo modificar una tabla existente. El siguiente paso es conocer qué sucede cuando necesitamos eliminar una tabla completa de la base de datos.

Para eso existe la sentencia DROP TABLE, que permite eliminar una tabla y su contenido. En el próximo artículo vamos a estudiar su sintaxis y sus principales características.
