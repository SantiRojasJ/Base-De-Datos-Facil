Fundamentos SQL

10 ejercicios prácticos para comenzar

Progreso 0 / 10
01
DDL

CREATE DATABASE

Crear una base de datos llamada Biblioteca.

Luego seleccionarla para trabajar sobre ella.

Intentos: 0/3
💡 Pista

Primero creá la base de datos con CREATE DATABASE, y luego seleccionala con USE.

Solución 
CREATE DATABASE Biblioteca;
USE Biblioteca;
02
DDL

CREATE TABLE

Dentro de la base de datos Biblioteca crear una tabla llamada Libros con los siguientes campos:

  • id_libro INT PRIMARY KEY
  • titulo VARCHAR(100)
  • autor VARCHAR(100)
  • anio_publicacion INT
Intentos: 0/3
💡 Pista

Definí cada columna con su nombre y tipo de dato. La PRIMARY KEY identifica cada fila.

Solución 
CREATE TABLE Libros (
    id_libro INT PRIMARY KEY,
    titulo VARCHAR(100),
    autor VARCHAR(100),
    anio_publicacion INT
);
03
DML

INSERT

Insertar 5 libros distintos dentro de la tabla Libros.

Pensá en libros reales con títulos, autores y años de publicación variados.

Intentos: 0/3
💡 Pista

Usá INSERT INTO Libros VALUES (valor1, valor2, ...) para cada libro.

Solución 
INSERT INTO Libros VALUES (1, 'El Principito', 'Antoine de Saint-Exupéry', 1943);
INSERT INTO Libros VALUES (2, 'Cien Años de Soledad', 'Gabriel García Márquez', 1967);
INSERT INTO Libros VALUES (3, 'Don Quijote', 'Miguel de Cervantes', 1605);
INSERT INTO Libros VALUES (4, '1984', 'George Orwell', 1949);
INSERT INTO Libros VALUES (5, 'La Sombra del Viento', 'Carlos Ruiz Zafón', 2001);
04
DML

SELECT

Mostrar todos los registros almacenados en la tabla Libros.

Intentos: 0/3
💡 Pista

El asterisco * selecciona todas las columnas de la tabla.

Solución 
SELECT * FROM Libros;
05
DML

SELECT COLUMNAS

Mostrar únicamente las siguientes columnas:

  • titulo
  • autor
Intentos: 0/3
💡 Pista

Listá las columnas que querés ver separadas por comas después de SELECT.

Solución 
SELECT titulo, autor FROM Libros;
06
DML

WHERE

Mostrar los libros publicados después del año 2015.

Intentos: 0/3
💡 Pista

WHERE filtra filas. Para comparar números no necesitás comillas.

Solución 
SELECT * FROM Libros WHERE anio_publicacion > 2015;
07
DML

UPDATE

Actualizar el título de un libro utilizando su id.

Intentos: 0/3
💡 Pista

UPDATE tabla SET columna = nuevo_valor WHERE condición;

Solución 
UPDATE Libros SET titulo = 'Nuevo Titulo' WHERE id_libro = 1;
08
DML

DELETE

Eliminar un libro de la tabla utilizando su id.

Intentos: 0/3
💡 Pista

DELETE FROM tabla WHERE condición; siempre usá WHERE para no borrar todo.

Solución 
DELETE FROM Libros WHERE id_libro = 1;
09
DML

ORDER BY

Listar los libros ordenados por año de publicación descendente.

Intentos: 0/3
💡 Pista

ORDER BY ordena los resultados. DESC es de mayor a menor.

Solución 
SELECT * FROM Libros ORDER BY anio_publicacion DESC;
10
Integrador

Ejercicio Integrador

Crear una base de datos llamada Universidad.

Crear una tabla Alumnos con los siguientes campos:

  • id_alumno
  • nombre
  • apellido
  • edad

Insertar 5 alumnos.

Mostrar únicamente los alumnos mayores de 20 años ordenados alfabéticamente por apellido.

Intentos: 0/3
💡 Pista

Combiná todo: CREATE DATABASE, CREATE TABLE, INSERT y un SELECT con WHERE y ORDER BY.

Solución 
CREATE DATABASE Universidad;
USE Universidad;

CREATE TABLE Alumnos (
    id_alumno INT PRIMARY KEY,
    nombre VARCHAR(100),
    apellido VARCHAR(100),
    edad INT
);

INSERT INTO Alumnos VALUES (1, 'Juan', 'García', 22);
INSERT INTO Alumnos VALUES (2, 'María', 'López', 19);
INSERT INTO Alumnos VALUES (3, 'Carlos', 'Martínez', 24);
INSERT INTO Alumnos VALUES (4, 'Ana', 'Rodríguez', 21);
INSERT INTO Alumnos VALUES (5, 'Pedro', 'Sánchez', 18);

SELECT * FROM Alumnos WHERE edad > 20 ORDER BY apellido ASC;
