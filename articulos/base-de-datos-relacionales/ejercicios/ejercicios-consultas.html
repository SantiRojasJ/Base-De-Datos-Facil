Consultas SQL

10 ejercicios de consultas intermedias

Progreso 0 / 10
01
JOIN

INNER JOIN

Dadas las tablas Alumnos y Carreras, mostrar el nombre del alumno y el nombre de su carrera.

Alumnos: id_alumno, nombre, id_carrera

Carreras: id_carrera, nombre_carrera

Intentos: 0/3
💡 Pista

INNER JOIN combina filas que tienen coincidencia en ambas tablas. Usá ON para indicar la condición.

Solución 
SELECT A.nombre, C.nombre_carrera
FROM Alumnos A
INNER JOIN Carreras C ON A.id_carrera = C.id_carrera;
02
JOIN

LEFT JOIN

Mostrar todos los alumnos y su carrera (si tienen una). Los alumnos sin carrera también deben aparecer.

Intentos: 0/3
💡 Pista

LEFT JOIN trae todas las filas de la tabla izquierda, aunque no haya coincidencia en la derecha.

Solución 
SELECT A.nombre, C.nombre_carrera
FROM Alumnos A
LEFT JOIN Carreras C ON A.id_carrera = C.id_carrera;
03
JOIN

RIGHT JOIN

Mostrar todas las carreras y los alumnos que cursan cada una. Las carreras sin alumnos también deben aparecer.

Intentos: 0/3
💡 Pista

RIGHT JOIN trae todas las filas de la tabla derecha, aunque no haya coincidencia en la izquierda.

Solución 
SELECT A.nombre, C.nombre_carrera
FROM Alumnos A
RIGHT JOIN Carreras C ON A.id_carrera = C.id_carrera;
04
Agregación

GROUP BY

Contar cuántos alumnos hay en cada carrera.

Mostrar el nombre de la carrera y la cantidad.

Intentos: 0/3
💡 Pista

GROUP BY agrupa filas por columna. COUNT(*) cuenta las filas de cada grupo.

Solución 
SELECT C.nombre_carrera, COUNT(*) AS cantidad
FROM Alumnos A
INNER JOIN Carreras C ON A.id_carrera = C.id_carrera
GROUP BY C.nombre_carrera;
05
Agregación

HAVING

Mostrar las carreras que tienen más de 3 alumnos.

Intentos: 0/3
💡 Pista

HAVING filtra después de GROUP BY. Es como WHERE pero para grupos.

Solución 
SELECT C.nombre_carrera, COUNT(*) AS cantidad
FROM Alumnos A
INNER JOIN Carreras C ON A.id_carrera = C.id_carrera
GROUP BY C.nombre_carrera
HAVING COUNT(*) > 3;
06
Subconsulta

WHERE IN

Mostrar los alumnos que cursan una carrera que empieza con "S" usando una subconsulta.

Intentos: 0/3
💡 Pista

Usá WHERE id_carrera IN (SELECT id_carrera FROM Carreras WHERE nombre_carrera LIKE 'S%').

Solución 
SELECT * FROM Alumnos
WHERE id_carrera IN (
    SELECT id_carrera FROM Carreras
    WHERE nombre_carrera LIKE 'S%'
);
07
Filtro

LIKE

Mostrar los alumnos cuyo nombre empieza con "A".

Intentos: 0/3
💡 Pista

LIKE busca patrones. El % es un comodín para cualquier carácter.

Solución 
SELECT * FROM Alumnos WHERE nombre LIKE 'A%';
08
Filtro

BETWEEN

Mostrar los alumnos con edad entre 20 y 25 años (incluidos).

Intentos: 0/3
💡 Pista

BETWEEN incluye ambos valores extremos. Es equivalente a >= y <=.

Solución 
SELECT * FROM Alumnos WHERE edad BETWEEN 20 AND 25;
09
Avanzado

JOIN + WHERE + ORDER BY

Mostrar el nombre del alumno y su carrera, pero solo los que cursan Ingeniería en Sistemas.

Ordenar los resultados por nombre del alumno alfabéticamente.

Intentos: 0/3
💡 Pista

Combiná INNER JOIN con WHERE para filtrar y ORDER BY para ordenar.

Solución 
SELECT A.nombre, C.nombre_carrera
FROM Alumnos A
INNER JOIN Carreras C ON A.id_carrera = C.id_carrera
WHERE C.nombre_carrera = 'Ingeniería en Sistemas'
ORDER BY A.nombre ASC;
10
Integrador

Ejercicio Integrador

Dadas las tablas Alumnos, Carreras y Materias:

  • Alumnos: id_alumno, nombre, id_carrera
  • Carreras: id_carrera, nombre_carrera
  • Materias: id_materia, nombre_materia, id_carrera

Mostrar el nombre de la carrera, la cantidad de alumnos y la cantidad de materias de cada carrera.

Mostrar solo las carreras con más de 2 alumnos, ordenadas por cantidad de alumnos de mayor a menor.

Intentos: 0/3
💡 Pista

Usá subconsultas para contar alumnos y materias por carrera, o combiná JOINs con GROUP BY y HAVING.

Solución 
SELECT
    C.nombre_carrera,
    (SELECT COUNT(*) FROM Alumnos A WHERE A.id_carrera = C.id_carrera) AS cantidad_alumnos,
    (SELECT COUNT(*) FROM Materias M WHERE M.id_carrera = C.id_carrera) AS cantidad_materias
FROM Carreras C
HAVING cantidad_alumnos > 2
ORDER BY cantidad_alumnos DESC;
