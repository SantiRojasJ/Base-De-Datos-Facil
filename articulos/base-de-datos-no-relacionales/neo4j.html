¿Qué es una Base de Datos de Grafos?

A diferencia de las bases de datos que venimos viendo, las de Grafos no se preocupan tanto por el "dato suelto", sino por cómo se relaciona con los demás. En lugar de tablas con filas, acá usamos una estructura de red.

Los tres pilares de un grafo:

  • Nodos: Son los objetos o entidades (ej: una "Persona", un "Producto").
  • Relaciones: Son las flechas que conectan los nodos. Siempre tienen un nombre y una dirección (ej: "Ana" -> ES_AMIGA_DE -> "Carlos").
  • Propiedades: Es la información extra que guardamos dentro de los nodos o relaciones (ej: la "edad" de la persona o la "fecha" desde que son amigos).

Introducción a Neo4j

Neo4j es la base de datos de grafos más popular del mundo. Está escrita en Java y es la herramienta perfecta cuando las relaciones entre tus datos son igual de importantes que los datos mismos.

Cypher: El lenguaje de Neo4j

Neo4j no usa SQL, usa un lenguaje llamado Cypher. Lo mejor de Cypher es que es muy visual: literal usás paréntesis para los nodos y flechas para las relaciones.

Ejemplo de creación:

// Creamos a Ana y Carlos, y los conectamos
CREATE (a:Persona {nombre: 'Ana', edad: 30})
CREATE (b:Persona {nombre: 'Carlos', edad: 35})
CREATE (a)-[:AMIGO_DE]->(b);

Operaciones básicas en Neo4j

Siguiendo la guía de nuestra unidad, estas son las jugadas básicas que tenés que saber:

  • Consultar (MATCH): Para buscar datos. Si querés ver todos los amigos de Ana:
    MATCH (p:Persona {nombre: 'Ana'})-[:AMIGO_DE]->(amigo) RETURN amigo
  • Actualizar (SET): Para cambiar un dato. Por ejemplo, si Ana cumple años:
    MATCH (p:Persona {nombre: 'Ana'}) SET p.edad = 31
  • Borrar (DETACH DELETE): Para eliminar un nodo. En grafos, no podés borrar algo que tiene conexiones sueltas, por eso usamos DETACH para cortar todas las flechas antes de borrar el nodo:
    MATCH (p:Persona {nombre: 'Carlos'}) DETACH DELETE p

¿Cuándo usar Neo4j?

  • Redes Sociales: Para calcular quién conoce a quién o sugerir nuevos amigos.
  • Sistemas de Recomendación: "A los que compraron este celular, también les gustó este protector".
  • Detección de Fraude: Para ver patrones de transferencias raras entre cuentas sospechosas.
  • Logística y Rutas: Para encontrar el camino más corto entre dos puntos.

Ventajas y Desventajas

Ventajas Desventajas
Rendimiento increíble en consultas de relaciones profundas. No es tan eficiente para procesar grandes volúmenes de datos que no están conectados.
Modelo de datos muy natural y fácil de entender. Cypher tiene una curva de aprendizaje si venís muy acostumbrado a SQL.
